# 学生实现目录

每位同学在这里创建自己的目录，例如：

```text
src/
└── your-id/
    ├── README.md
    ├── REPORT.md
    ├── CMakeLists.txt
    └── ...
```

目录名使用小写英文字母、数字或短横线，避免空格、中文和大小写混用。请不要直接修改其他同学的目录，也不要把公共资料复制到个人目录。

统一使用 C++ 和 OpenCV C++ 接口实现。每个个人目录均为独立的 CMake 项目，由同学自行编写源代码和 `CMakeLists.txt`；按 [构建约定](../CONTRIBUTING.md#cmake-构建约定) 在 Linux 下配置、编译和运行。
